# 精选商城 · 微信小程序 Demo

一个**原生微信小程序**实现的电商购物 Demo，无后端依赖，商品、地址与订单数据通过本地 `storage` 模拟。

## 功能

- **首页**：搜索入口（点击跳独立搜索页）、轮播 Banner（自定义指示点，**点击跳商品/分类**）、分类筛选 + **排序与价格筛选**、**限时秒杀横滑区块**（秒杀价 / 已售进度条 / 倒计时 / 查看全部）、为你推荐、商品网格，支持**下拉刷新**
- **搜索**：独立搜索页——搜索历史（可清空）、热搜词、输入实时联想（防抖），结果支持**排序与价格筛选**，网格点击进详情
- **限时秒杀**：首页秒杀区块 + 秒杀专场页（倒计时 / 秒杀价网格）；秒杀商品在详情页显示限时角标与倒计时，加入购物车 / 立即购买按**秒杀价**结算（加购时价格固化）
- **商品详情**：顶部轮播大图（自动播放、自定义指示点、点击全屏预览）、**多规格 SKU 选择（颜色/尺码，价格与库存随规格变化，半屏弹层）**、价格（闪购价展示）、销量库存、数量选择、**收藏开关**、加入购物车 / 立即购买，下拉浏览图文详情（详细介绍 + 详情大图，点击可预览）
- **购物车**：勾选、数量加减、删除、全选、合计结算、tabBar 角标同步
- **确认订单**：收货地址选择（可新增/编辑）、商品清单、金额明细（商品金额/运费/优惠券/积分抵扣/应付）、订单备注、库存校验、提交订单
- **收货地址**：地址列表、新增/编辑/删除、设默认（原生省市区选择器）；结算页点选回传
- **支付**：下单后拉起支付——自定义「模拟支付」底部弹层（样式仿微信支付），可切换真实微信支付 v3（失败自动回退模拟），支付成功进入**支付成功页**
- **订单中心**：全部 / 待付款 / 待发货 / 待收货 / 已完成 / 售后 / 已退款 / 已取消 切换，**订单搜索**（订单号 / 商品名），卡片进详情，待付款倒计时，去支付、取消订单、确认收货，支持**下拉刷新**
- **订单详情**：状态与倒计时、收货地址、商品清单（含规格）、金额明细（含积分抵扣 / 退款金额）、订单信息（订单号可**一键复制**）、去支付 / 取消 / **申请退款** / **按商品申请售后** / 模拟发货 / **查看物流** / 确认收货 / 删除 / 再次购买
- **物流跟踪**：待收货 / 已完成订单可查看**模拟物流时间轴**（由订单确定性生成，最新在上）
- **退款 / 售后**：待发货 / 待收货订单可**整单申请退款** → 售后中（可撤销 / 商家驳回 / 同意退款）→ **已退款**，退款释放库存并退回积分；亦可**按商品申请售后**（仅退款 / 退款退货），卖家演示「同意退款（回补库存）/ 拒绝」，全部商品退款完成后订单转为「已退款」
- **积分签到**：每日签到领积分，结算页**积分抵扣**（100 积分 = 1 元，与优惠券可叠加且不超商品金额），取消 / 超时 / 退款自动退回，含积分明细账本
- **收藏**：详情页收藏开关，收藏列表页网格展示（可快捷取消，支持排序），数据本地持久化
- **列表排序与筛选**：首页 / 搜索 / 收藏结果支持综合、销量、价格（升/降切换）、最新排序；首页与搜索另支持价格区间筛选（0-100 / 100-500 / 500-1000 / 1000+）
- **优惠券**：领券中心（新人券/满减券）领取、我的券（未使用/已使用/已过期）列表；结算页选择优惠券抵扣，取消待付款订单自动回退，金额计算防超扣
- **商品评价**：商品详情页评价汇总（平均分 + 预览），评价列表页；订单完成后逐商品评价（评分 + 文字 + 晒图，最多 3 张）
- **登录 / 会员中心**：微信原生头像昵称能力（`chooseAvatar` + `type="nickname"`）登录，我的页展示头像/昵称/ID，支持编辑资料与退出登录
- **我的**：个人中心、订单快捷入口（switchTab 跳订单 tab）、会员中心、消息中心、收货地址、我的收藏、优惠券、积分签到（显示余额）、**分销中心**、**我的拼团**、**门店列表**、帮助与客服、设置、分享
- **帮助与客服**：FAQ 手风琴 + **微信客服会话**（`button open-type="contact"`）
- **设置**：消息通知开关（联动通知中心，关闭后不再写入订单/拼团/分销/系统/促销通知）、清除搜索历史、重置演示数据（含全部新增模块 seed）、关于
- **分享**：分享给好友 + **分享到朋友圈**（`onShareTimeline`，首页 / 详情 / 秒杀专场）
- **会员体系**：会员中心（等级、成长值进度、权益列表）、等级折扣（普通/银卡 98 折/金卡 95 折/钻石 92 折）在确认订单页生效
- **消息通知**：消息中心按 **订单 / 拼团 / 分销 / 系统 / 促销** 分类筛选，点通知直达订单详情或拼团详情，未读角标同步到「我的」；通知由订单与拼团事件**自动写入**
- **多门店**：门店列表（定位排序 / 搜索 / 电话 / 导航 / 设为自提门店）、门店详情、结算选门店；**到店自提免运费**，并按**门店分仓库存**校验、扣减与回补
- **拼团**：拼团专区（拼团价 / 进行中的团 / 我的拼团）、拼团详情（进度 / 成员 / 倒计时）；**发起或参与拼团均走真实下单 + 支付**，付款成功才开团 / 入团，满员即成团并推送通知，订单号回写拼团
- **分销**：分销中心（未申请 / 审核中 / 已拒绝 / 已是分销员四态）、佣金明细、我的团队、提现记录；**推广链接带 agentId**，好友下单支付后佣金自动入账
- **商品对比**：详情页加入对比，浮条进入对比页（多维度对比 + 差异分析）
- **直播**：直播间列表 / 直播详情，首页直播入口（直播中闪烁）
- **AR 试穿**：商品详情 AR 入口，支持 AR 试穿/试用的商品可在预览页体验

## 下单支付流程

```
购物车结算 / 商品立即购买（详情页先选规格，无规格商品自动跳过；秒杀商品按秒杀价）
        ↓
确认订单页（选地址 → 选优惠券 → 积分抵扣 → 金额明细 → 备注 → 提交）
        ↓
创建订单（按 SKU 校验库存，占用优惠券与积分，待付款 30 分钟超时自动取消）
        ↓
模拟支付 / 微信支付（成功后按 SKU 扣减库存）
        ↓
支付成功页 → 订单详情 → 订单中心（完成后可逐商品评价 / 申请售后）
```

- 支付成功时才**扣减商品库存**（按 SKU 维度）；取消待付款订单不会回补（未扣），已扣库存的订单取消时自动回补
- 下单时使用优惠券会**占用**该券、使用积分会**占用**积分；取消 / 超时取消待付款订单时自动回退
- 待付款订单展示倒计时，超时自动取消并归入「已取消」
- 订单详情「待发货」状态提供**模拟发货**按钮（Demo 用，替代真实商家的发货动作），方便演示完整链路
- 订单状态：`1 待付款 → 2 待发货 → 3 待收货 → 4 已完成`，`5 已取消`，退款 / 售后走 `6 售后中 → 7 已退款`

## 退款流程

```
待发货 / 待收货订单 → 订单详情「申请退款」→ 售后中(6)
        ↓
撤销申请（回待发货/待收货） 或  商家同意退款（模拟同意退款 → 已退款(7)）
```

- 申请退款即**释放库存**（置 `stockDeducted=false`，保证只回补一次）；撤销 / 驳回后不重新扣库存（Demo 约定）
- **同意退款退回积分**；优惠券**不回退**（贴合真实电商）
- 售后（按商品）：任一商品申请售后订单即进入「售后中」；卖家同意退款时**回补该商品库存**；全部商品退款完成后订单变「已退款」，部分退款处理完成后回退原状态
- 自提订单退款时库存**回补到原门店分仓**（不是总仓），避免总仓虚增

## 分销流程

```
分销中心「立即申请」（需登录）→ 审核中
        ↓  平台审核（演示用「模拟平台审核」）
已是分销员 → 分享推广链接（路径带 agentId）
        ↓
好友点链接进入（首页/详情记录推广位）→ 下单 → 支付成功
        ↓
按商品推广比例计算佣金 → 入账 + 分销通知
        ↓
申请提现（冻结）→ 模拟打款（已到账 / 拒绝退回可提现）
```

- 佣金按**商品维度**逐项计算（`promoteGoods` 里各商品可配不同比例），非可分销商品不计佣金
- 同一分销员 + 同一订单**只结算一次**（幂等），重复支付回调不会重复计佣
- 用户 id 一律取真实登录态（`utils/user`），不再硬编码 `user_001`
- 申请被拒后可重新申请；提现记录「处理中」可点击模拟打款结果

## 拼团流程

```
拼团专区 / 商品详情「发起拼团」→ 拼团订单确认页（拼团价 + 地址 + 数量）
参团：好友分享 → 拼团详情「立即参团」→ 同上（带 groupId）
        ↓
创建订单（按拼团价结算，记录 groupBuyId / groupPrice / isGroupBuy）→ 支付
        ↓
支付成功才落拼团：发起 → createGroup；参与 → joinGroup（满员即成团）
        ↓
订单号回写拼团（我的拼团可直达订单详情）；成团 / 流局均推送通知
```

- **未支付不建团**：付款成功才计入拼团，取消支付则订单停在待付款
- 拼团订单是普通订单，照常进入订单中心，状态流转与其他订单一致
- 拼团详情进页面会判定过期未成团的团为「拼团失败」并推送通知
- 拼团次数受 `limitPerUser` 限制

## 门店自提

- 门店列表可从「我的 → 门店列表」进入，也可在确认订单页选门店；「自提」按钮即把该店设为自提门店
- 选择**到店自提后免运费**（快递满 `FREE_SHIPPING_THRESHOLD` 免运费，否则收 `SHIPPING_FEE`）
- 自提订单走**门店分仓库存**（`storeData.storeStock`，按「门店 + 商品」确定性分配容量 5~20），与总仓 `goods.stock` 相互独立：自提扣门店仓、快递扣总仓
- 自提订单「模拟发货」语义为**备货完成**，生成 4 位**提货码**并在订单详情展示

## 消息通知

- 通知由业务事件**自动写入**（`utils/mock.js` 的订单状态机 + 拼团模块），无需页面手动触发：
  - 下单、支付成功、发货（自提为「备货完成可提货」）、确认收货、取消、超时取消
  - 退款申请、退款成功、退款被拒
  - 拼团成功、拼团失败、佣金入账
- 类型映射设置开关（订单/拼团/分销 → 订单通知，系统 → 系统通知，促销 → 促销通知），在设置页关闭后 `addNotification` 直接丢弃，不写库
- 点通知可直达订单详情（带 `orderId`）或拼团详情（带 `groupId`）

## 运行方式

1. 安装[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)（稳定版即可）
2. 打开开发者工具 → **导入项目** → 选择本目录 `mini-shop-demo`
3. AppID 选择「测试号」（或填写你自己的 AppID）
4. 商品图片使用网络占位图，若加载不出，在「详情 → 本地设置」勾选 **不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书**（本工程已在 `project.config.json` 中预置 `urlCheck: false`，通常无需手动勾选）

## 数据说明

- 购物车存于 storage key `cartList`（条目带 `skuKey`/`spec`，同商品不同规格为两条，闪购价加购时固化），收货地址存于 `addressList`，订单存于 `orderList`（条目带规格），收藏存于 `favoriteList`（商品 id 数组），搜索历史存于 `searchHistory`，用户信息存于 `userInfo`，优惠券存于 `couponList`，评价存于 `reviewList`，售后存于 `afterSaleList`，设置存于 `settingsList`，积分存于 `pointsData`（单对象）

## 秒杀说明

- 首页秒杀区块与秒杀专场页展示 `flashPrice` 秒杀价、已售进度、倒计时；`flashSold / flashStock` 仅作展示，实际下单库存仍走统一 `goods.stock`
- 秒杀商品在详情页显示「限时」角标与倒计时，加入购物车 / 立即购买按秒杀价结算（价格在加入购物车时固化）
- 秒杀价由 `mock.getEffectivePrice(goods)` 计算，过期自动回落原价

## 积分说明

- 积分规则：`100 积分 = 1 元`，每日签到 `+5 积分`（`utils/points.js` 可调）
- 结算页「积分抵扣」上限为 `min(积分余额, 商品金额 − 优惠券金额)`，与优惠券叠加不超商品金额，余额不足 100 时不可用
- 下单即**占用**积分（同优惠券），取消 / 超时取消 / 退款成功时**原路退回**；积分明细记录在 `pointsData.ledger`

## 支付说明

支付默认使用**模拟模式**（`utils/config.js` 中 `PAY_MODE: 'mock'`）：下单后弹出自定义「模拟支付」**底部弹层**（样式仿真实微信支付：商户/金额/确认支付/取消），点「确认支付」即完成支付，无需后端和商户号，开发者工具里可直接演示完整流程。订单中心「待付款」订单点「去支付」、订单详情页「去支付」同样走支付流程。

### 切换真实微信支付

真实支付采用微信支付 **v3 JSAPI**，需要商户号与自建后端（本工程已内置零依赖 Node 后端，见 `server/`）：

1. 配置后端：复制 `server/config.example.json` 为 `server/config.json`，填入：
   - `appid` / `appsecret`：小程序的 AppID 与 AppSecret（`appsecret` 用于 code 换 openid）
   - `mchid` / `mchSerialNo`：微信支付商户号、商户 API 证书序列号
   - `apiV3Key`：API v3 密钥（32 位）
   - `privateKeyPath` / `platformCertPath`：商户私钥与微信支付平台证书路径
   - `notifyUrl`：**公网 HTTPS** 的回调地址（如 `https://你的域名/api/pay/notify`）
2. 启动后端：`cd server && npm start`（零依赖，无需 `npm install`），或直接 `node server/index.js`
3. 前端切换：`utils/config.js` 中 `PAY_MODE` 改为 `'real'`，`PAY_SERVER_URL` 指向后端地址
4. 重新导入/预览小程序：下单后走 `wx.login → 统一下单 → wx.requestPayment`；真实支付失败时会弹窗询问是否改用模拟支付兜底

### 注意事项

- **测试号 / 开发者工具无法完成真实 `wx.requestPayment`**（微信支付能力未开通），真实支付需在正式小程序 + 已开通微信支付的商户号下于真机测试
- 开发者工具中 `urlCheck: false` 已预置，可访问 `http://127.0.0.1:3000` 本地后端；真机需把后端地址换成 **HTTPS 域名**，并在小程序后台「开发 → 开发管理 → 服务器域名」配置 request 合法域名
- 生产环境应在 `server/index.js` 的 `/api/pay/notify` 中按 `out_trade_no` 更新订单状态并做幂等处理（当前仅打印日志）
